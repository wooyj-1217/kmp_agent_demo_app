# v1 로컬 검토 보고서

SRC-007 이후 현재 보고서는 `rtk proxy python3 tools/v1-report/agreement.py`로 갱신한다. 기존 `generate.py`는 과거 manifest/baseline이 현재 승인 목표와 다르면 중단하며 기존 상세 HTML을 덮어쓰지 않는다. 현재 보고서 주소는 `/agreement-review/index.html`이다. 과거 보고서와 ZIP은 당시 이력으로 보존한다.

저장소 루트에서 `rtk proxy python3 tools/v1-report/generate.py`로 **수동 재생성**한다.
`rtk proxy python3 tools/v1-report/serve.py --port 8773`으로 보고서 폴더만 loopback에 제공한다.
접속: http://127.0.0.1:8773/

원본은 기존 요구사항·디자인·API·인수 상태 문서, 작업 원장, 실행 summary/XML 및 소스/빌드 설정이다.
`reports/v1`은 파생 HTML·읽기용 근거 사본·선별 캡처·SVG·무결성 검사 결과다. 별도 상태 원장이 아니다.
개별 기대 결과는 requirements의 AC 표에서 읽고 기존 플랫폼 결과는 acceptance-status 표에서 읽는다.
확대·보조기술·탐색 공백과 제안은 명시적으로 분리한다. 원본 문서를 수정해 구현에 맞춘 기대값을 만들지 않는다.

기술 설명·도식·AC 실행 절차는 조사한 코드의 설명을 변환 스크립트에서 제공한다.
설정/구현이 변경되면 설명도 검토해야 한다. 파일 해시 불일치는 보고서에 노출하며 자동으로 새 PASS를 만들지 않는다.
현재 버전/관측 시각은 provenance와 설치 환경 근거에 표시한다. 설치 존재와 실행 통과를 구분한다.

DB는 생성 시 접속하지 않는다. `.harness/v1/html-report-runtime.json`의 읽기 전용 관측을 해당 시점으로만 재사용한다.
메모 본문/시도 키/DB 파일, 개인 설정, 원본 세션 로그를 복사하지 않는다.
소스 문서 내부 링크는 이중 탐색 가능한 원본 링크로 재작성하지 않고 텍스트로 보존한다.
보고서에서 클릭하는 상대 링크는 제공 폴더 내부의 읽기용 사본으로만 연결한다.

제품 시험 전체 재실행, 라이브러리 업그레이드, 제품/설치 하네스 수정, 커밋/푸시/배포는 수행하지 않는다.
브라우저 UI 검사는 제품 검증 상태를 바꾸는 근거가 아니며 별도 보고서 표시 검증으로 보존한다.
