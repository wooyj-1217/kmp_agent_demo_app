# 독립 메모앱 현재 기획

상태: 확정 기획에 따라 구현·검증 중 — 새 사용자 요청만 제품 입력으로 사용. 과거 앱의 Git 이력·소스·디자인·명세를 가져오거나 재사용하지 않는다. 운영 지침·하네스는 도구로 사용한다.

## 확정 입력

- 사용자 요청: 독립 시행으로 메모앱을 처음부터 만든다. 이전 버전을 Git에서 가져와 참고하는 행위는 금지한다.
- 기존 작업물과 검증 증거는 보존한다. 새 제품 소스는 별도 디렉터리에 작성한다.

## 현재 기능 범위

빠르게 생각을 기록하고 다시 찾는 개인 메모앱. 제목·본문 작성/수정, 목록과 검색, 고정, 삭제·휴지통·복원·내보내기와 개인 계정의 서버 동기화를 포함한다. 한국어 기본 UI와 좁은 화면 대응, 키보드 접근성을 구현·검증 대상으로 둔다. 이름·색·레이아웃은 새로 설계한다.

## 이번 세션의 사용자 결정

사용자가 각 질문에 직접 답변했다. 이전 제품의 결정·검토 결과는 승계하지 않았다.

- 플랫폼: **Android·iOS·Web**.
- 저장: **서버 동기화 포함**.
- 서버: **새 전용 서버도 함께 구현**.
- 기획 묶음: **제안한 기획안으로 진행**. 이메일·비밀번호 개인 계정, 오프라인 편집·재전송, 동시 수정의 충돌 사본, 작성·검색·고정·휴지통·복원·내보내기를 포함한다. 공유·협업은 후속 범위다.
- 원문 식별자: 세션 `01a1c3f9-7990-7e90-bd59-c76012f79c50`, 질문 도구 호출 `call_27a3200b91674b4681a1776d37fb91a3`, `call_fa6c2ed300884877acfa9ba0dae7ec3e`, `call_d9946bd385c648b594da42cf83f3923a`.

에이전트 구현 선택: 새 이름 **틈**, 녹색·종이색 화면, 공통 HTML/CSS/JavaScript 화면을 앱에 번들하는 Android WebView/iOS WKWebView 및 Web 구성. Python 표준 라이브러리·SQLite 서버. 이 선택은 사용자에게 스택 선택으로 승인받았다고 주장하지 않는다. KMP 코드 재사용은 없다.

## 초안 제안과 현재 결정의 관계

- 플랫폼 초안의 Web 우선 대안은 채택되지 않았다. 사용자가 이번 시행에서 Android·iOS·Web을 선택했다.
- 저장 초안의 기기 저장 + 내보내기/가져오기 추천안은 채택되지 않았다. 사용자가 서버 동기화·새 전용 서버를 선택하고, 내보내기가 포함된 기획 묶음을 확정했다. 가져오기는 현재 확정 기능 목록에 포함하지 않는다.
- 플랫폼·데이터 정책의 답변 대기는 해소됐다. 시각·스택 세부 사항은 위에 구분한 에이전트 구현 선택이며, 실제 구현·검증 사실은 별도 검증 기록을 따른다.

## 수용 기준

1. 메모 생성·수정 후 앱을 다시 열면 저장된 내용을 읽을 수 있다.
2. 제목·본문 검색, 고정과 정렬이 일관되게 작동한다.
3. 삭제한 메모는 휴지통에서 복원할 수 있고 영구 삭제는 명확히 확인한다.
4. 저장 실패 시 입력을 보존하고 실패와 재시도 방법을 표시한다.
5. 빈 목록·검색 결과 없음·긴 내용·좁은 화면을 검증한다.
6. 확정된 플랫폼마다 빌드와 실제 사용자 흐름을 검증하고 미실행을 구분한다.
