## 발견·수정

1. 서버의 최초 INSERT 값 개수 오류: 작성 시 503 발생. 생성 시간을 명시한 스키마·INSERT로 수정하고 서버 검사 통과.
2. 최신 스냅샷으로 미전송 변경의 기준 버전을 올릴 수 있는 문제: 오래된 변경의 기준 버전 유지 및 실제 이전 요청 acknowledgement revision만 적용. 클라이언트 회귀 검사 통과.
3. iOS 파일 문서의 module 스크립트 초기화 실패: import가 없는 공통 스크립트를 defer classic으로 변경. 실제 iOS 화면 초기화·로그인 창 동작 확인.
4. 좁은 화면에서 계정·전체 내보내기 접근 경로 누락: 모바일 ‘나’ 버튼 추가.
5. Android 개발 원격 주소의 HTTPS→HTTP 혼합 콘텐츠 연결 차단: 디버그 가상 문서 origin을 HTTP로 분리하고 네트워크 예외는 로컬에 한정. 릴리스는 HTTPS이며 혼합 콘텐츠 차단 유지. Android 실제 계측 재검증 통과.
6. 네이티브 테스트의 reload 대기가 이전 문서에서 즉시 성공할 수 있는 문제: 문서별 marker가 사라진 새 문서에서만 저장된 메모를 검사하도록 보완. Android·iOS 실제 통합 재검증 통과.

## 하네스·운영 상태

이 세션의 v0.4.0 startup/hook은 앞선 별도 검증 기록에서 `VERIFIED/PASS`다. 독립 작업 run은 `MEMO-INDEPENDENT-20261110`, 전체 계획은 `MEMO-NEW-PLAN/DESIGN/BUILD/QA/REPORT`로 등록했다. 최초 필수 질문 원장 등록은 현재 세션 바인딩 부재로 실패했으며 실제 사용자 질문·답변은 정상 수신됐다. 이후 바인딩을 보완했다. 공식 managed 실행·검토 상태를 실제 구현 완료와 동일하다고 주장하지 않는다.

브라우저 자동화 host가 없어 연결된 대시보드를 열 수 없었다. Chrome 네이티브 CUA로 새 앱 Web을 검증했다. Android Emulator는 CUA 앱 이름으로 선택할 수 없어 실제 Android 계측 검사로 확인한다. iOS CUA의 붙여넣기/키 전달이 실패했으며 실제 WKWebView XCTest로 확인한다.

## 남은 확인·미실행

- 세 클라이언트 실데이터 대조 PASS: `sync-evidence.json`. Web CUA가 작성한 한국어 메모와 Android/iOS의 네이티브 검사 메모가 같은 새 서버·개인 계정의 동기화 응답에서 모두 확인됐다. 인증정보나 원문 전체는 요약 파일에 포함하지 않았다.
- 맥락 정리 담당 `/root/memo_context`가 새 문서만 검토했고 메인이 변경 4개와 해시를 대조·수락했다. `context-review.md` 참고. 이는 managed 작업 원장의 공식 DONE 판정과 별개다.
- 공개 HTTPS 배포·스토어 제출·실기기 서명 검증은 NOT_RUN (요청한 로컬 구현·검증과 구분)
- 긴 내용·전체 접근성·네이티브 파일 내보내기 OS 흐름은 위 검사 목록만으로 전체 PASS로 선언하지 않는다. 실제 실행·남은 한계는 최종 보고에 구분한다.

## 인도 상태

Web은 `http://127.0.0.1:8910`에서 실행 중이다. 새 계정을 만들거나 localhost 전용 QA 계정으로 동작을 확인할 수 있다. Android Debug APK는 `memo-next/android/build/outputs/apk/debug/android-debug.apk`, iOS 프로젝트는 `memo-next/ios/Teum.xcodeproj`다. 소스·문서 커밋·push·배포·기존 제품 데이터 마이그레이션은 수행하지 않았다. 서버 데이터·빌드·xcresult는 Git 제외 상태를 확인했다.

실제 구현·검증 체크리스트는 완료한 범위만 표시한다. 모든 접근성·긴 본문 성능·플랫폼 파일 선택기 수동 검수나 하네스의 공식 완료 게이트 전체를 통과했다는 뜻은 아니다.

최종 Android 뒤로 가기는 확인 창→계정 창→편집 목록→Activity 종료 순서로 처리하도록 보완했다. 이후 APK 재빌드 및 동일 실제 계측 검사 재실행이 5.764초에 통과했다. 새 프로젝트 전용 Gradle 8.14.3 래퍼는 공식 wrapper 태스크로 생성했다. 이전 프로젝트 래퍼는 참조하지 않았다.
