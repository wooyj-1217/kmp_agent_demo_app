## 화면·컴포넌트
SCREEN-LIST: 헤더 wordmark·제목·새로고침, 중앙 목록 영역 L-CONTENT, 하단 새 메모 작성. L-CARD는 비대화형 메모 카드이며 별도 상세 페이지·편집 기능을 추가하지 않는다. 본문은 pre-wrap을 유지하면서 최대 3줄로 표시하고 넘치는 내용은 말줄임 처리한다. 저장 본문 자체는 변경하지 않는다. 날짜는 카드 하단 보조 정보다. 최신순 배지를 제공한다. 샘플 순서는 고정이며 실제 서버 정렬·동률 키는 API 계약에서 정한다.

## 상태별 표시
STATE는 활성 main의 `data-state-id`, SCREEN은 `data-screen-id`다. 접두사를 생략하지 않는다.

## D0.4 사용자 피드백 반영
목록 본문 최대 3줄 미리보기, 작성 글자 수 초과 시 현재 수치만 빨간색(#9a302a)·굵게 표시한다. `/ 2,000`은 기본 보조색을 유지한다. 본문 하단의 “앞뒤 공백을 제외하고 최대 2,000자” 문구는 제거한다. 초과 오류 문구·저장 차단·공백 제거 및 2,000자 정책은 유지한다. 유효 길이로 돌아오면 수치 색상도 복귀한다. 원래 기획 커밋 이후 명시적 사용자 변경이며 해당 표시·스크롤·접근성 재검토는 NOT_RUN이다. 별도 전체 보기·제품 기능은 추가하지 않는다.

## v1 인계용 적용 우선순위 — SRC-005

현재 채택 기준은 본 문서의 최신 사용자 반응형 변경(D0.4-WEB)과 실제 공용 CSS/JS다. 이전 960px·고정 프레임·선택 장치 관련 제안은 이력으로 한정한다. 목록 3줄·독립 전체 보기 미추가, 작성 초과 수치만 빨간색·두 하단 조건 안내 제거를 유지한다. 토큰은 기존 가역 제안을 유지한다. 일반 미저장 초안의 새로고침/재진입 자동 복원은 없고, 화면 내 취소 확인은 유지한다. 저장 중/불확실 시도는 별도 복구 계약으로 보존하며 새로고침으로 새 작성에 진입하지 않게 한다. 앱 강제 종료를 UI로 막는다고 약속하지 않는다. 실제 영속/복구 검증은 제품 구현에서 수행한다. 최신 시안 검토의 공식 결과·테스트 출력 해시는 `.harness/v1/reviews/`와 기존 작업 원장의 V1-DESIGN에 연결하며 이전 PASS는 승계하지 않는다.
