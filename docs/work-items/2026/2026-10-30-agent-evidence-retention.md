## 요청과 범위

사용자가 에이전트 수정 증거는 PR을 올릴 때까지 보존하고 버전업 시 정리하는 운영 방식을 제안했다. 이 사용자 결정의 원문 ID는 UNKNOWN이며 이 대화가 근거다. 에이전트 수정 증거의 보존·정리 시점을 구체화한다. 증거의 실제 삭제·이전, 공통 kmp_agent 소스 수정, 제품 증거의 일괄 정리는 범위 밖이다.

## 결정과 이유

- 사용자 결정: PR 준비 동안 증거를 보존하고 에이전트 버전업 때 정리한다.
- 구현 규칙: PR 업로드 직후에는 리뷰·수정 검증이 필요하므로 계속 보존한다. 버전업 때 반영 완료 범위를 확인해 중복·임시 증거를 정리하고, 중요한 최종·실패·수정·재검증 원본과 결정 연결은 유지한다.
- 미반영 PR, 미해결 조사, 미확정 릴리스는 보존한다. 선택 커밋 설치를 릴리스 완료로 대체하지 않는다.
- 대체하는 이전 결정: 기존 산출물 정책의 일반적인 보관 규칙을 보완하며 중요한 원본 보존 원칙은 유지한다.
