## 요청과 범위

사용자는 남아 있는 네 가지 작업을 모두 진행하도록 요청했다: 현재 맥락 슬림화, 운영 절차와 과거 적용 이력 분리, 로컬 증거 관리, kmp_agent 공통 적용. 이후 증거 보관 방식 결정이 끝나지 않았음을 지적하여 작업을 중단했다. 최종 사용자 결정은 원본 증거를 로컬에서만 확인·보존하고 업로드·삭제·이동하지 않는 것이다. PR에는 수정 코드·문서와 검증 명령·결과 요약만 포함한다. 원문 ID는 UNKNOWN이다. 제품 동기화 구현·제품 정책 결정·릴리스·머지는 범위 밖이다.

## 계획과 소유 범위

- 메인: 공통 소스의 깨끗한 별도 브랜치, 로컬 증거 보존 규칙, 통합·검증·작업 기록. 원격 보관·복구 도구는 최종 결정으로 채택하지 않는다.
- 문서 정리 담당: context.md·agent-workflow.md 및 원문 보존 역사 파일만. 현재 기준과 과거 관측을 구분하고 기존 앵커를 유지한다.
- 증거 도구 초안 담당: evidence_archive.py와 관련 테스트 초안을 작성했으나 사용자 최종 결정으로 채택하지 않고 이번 작업이 만든 초안만 철회했다. 실제 기존 증거는 삭제·이동·원격 업로드하지 않았다.
- 종료 맥락 담당: 구현·검증 종료 후 실제 변경과 사용자 결정 대조. 메인이 별도 수락.

## 결정과 이유

- 현재 명세·맥락은 현재 기준을 짧게 유지하고, 과거 내용은 삭제 대신 원문 보존 기록으로 분리한다. 필요할 때만 해당 작업 기록과 원본을 읽는다.
- 최신 사용자 결정: 기존 .harness 원본은 로컬에 유지한다. 과거 증거 전체를 에이전트 일반 실행의 필수 입력으로 삼지 않는다. 현재 작업에 필요한 로컬 검증을 수행하고 PR에는 명령·결과 요약만 남긴다. 원본 증거·묶음의 커밋·PR 첨부·원격 보관은 수행하지 않는다. 버전업 점검도 실제 삭제·이동 권한은 아니다.
- 공통 원본의 기존 작업 트리는 dirty이므로 덮어쓰지 않는다. 원격 main을 새 clone한 별도 브랜치에서 제품 내용 없는 공통 정책·템플릿·도구만 적용한다. 설치된 releases는 수정하지 않는다.
- 이전 정책 보완: [산출물 관리 규칙](../../artifact-policy.md), [증거 보존 결정](2026-10-30-agent-evidence-retention.md), [커밋·기록 도입](2026-10-30-commit-hooks-artifacts.md).
