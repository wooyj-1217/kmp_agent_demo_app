## 요청과 범위

사용자는 커밋 규칙 작성에 이어 자동 검사 훅 설치를 요청하고, 산출물 정리 방식 개선도 실제 반영했는지 확인했다. 직전 작업은 커밋 규칙과 참조 연결까지만 작성했으며 산출물 관리 방식은 대화상 제안이었다. 이번에는 프로젝트 운영 규칙·템플릿과 로컬 훅으로 구체화한다. 제품 기능·공통 하네스 release는 변경하지 않는다.

## 결정과 이유

- 사용자 요청: 자동 커밋 검사 훅 설치와 산출물 정리 방식의 반영. 정확한 원문 ID는 UNKNOWN.
- 구현 선택: 외부 패키지 없이 Python 3와 Git의 `commit-msg` 훅 사용. 검사기는 메시지를 수정하지 않고 오류를 알린다. 기존 다른 훅 설정은 자동 덮어쓰지 않는다.
- 운영 규칙: 현재 명세·맥락에는 유효한 기준을 유지하고, 의미 있는 작업은 연도별 한 파일에서 이유·결정·결과·근거를 연결한다. 검색은 rg/Git에서 시작하며 수동 전체 이력 목록을 중복 유지하지 않는다.
- 대체하는 이전 설명: 직전 `context.md`의 커밋 규칙이 문서만이고 자동 hook은 없다는 설명을 이번 설치 사실로 갱신한다. 기존 Git 이력·원본 근거는 재작성하지 않는다.

## 결과와 현재 기준

- [커밋 규칙](../../commit-policy.md): 자동 검사 범위, 필수 본문 필드, 설치·해제·한계 반영.
- `.githooks/commit-msg`, `tools/check_commit_message.py`, `tools/install_git_hooks.py`, `tools/test_commit_hooks.py`: 저장소 버전 관리 가능한 훅과 검사 도구.
- 실제 로컬 `core.hooksPath=.githooks` 설치 확인. 새 clone에서는 설치 명령을 다시 실행해야 한다.
- [산출물 관리 규칙](../../artifact-policy.md), [작업 기록 안내](../README.md), [템플릿](../TEMPLATE.md) 신설. AGENTS.md·README.md·agent-workflow.md에서 연결.
- 과거 자료는 관련 기능 수정 시 점진 정리한다. 기존 산출물·증거의 일괄 이관·삭제, 외부 보관소, 검색 DB, 자동 정리는 수행하지 않았다.
- 로컬 훅은 우회 가능하며 CI/서버 강제 검사는 없다. 판단·검증의 진실성이나 산출물 갱신 자체는 자동 검사하지 않는다. 서버 동기화 미해결 등 기존 제품 상태는 그대로다.

## 검증과 변경 연결

- 실제 검증 대상: 위 기준 커밋 위의 이번 미커밋 훅·도구·문서 작업 트리. 소스 SHA-256와 검사 결과는 `.harness/commit-hooks-artifacts/validation.json`에 보존한다.
- 수행 검사: `python3 -B -m unittest discover -s tools -p test_commit_hooks.py -v`의 2개 테스트 메서드 통과. 제목·본문·호환성·revert 메시지 사례와 임시 저장소의 실제 커밋 차단/통과, 반복 설치·기존 훅 보존·주석 문자 처리 포함.
- 초기 실패: 빈 본문 필드가 다음 줄을 값으로 읽는 정규식 결함 발견. 수평 공백으로 제한해 수정 후 같은 회귀 통과.
- 실제 설치: `python3 tools/install_git_hooks.py` 성공 후 `git config --get core.hooksPath`에서 `.githooks` 확인. 현 저장소 훅 직접 호출의 정상/오류 메시지 판정은 validation.json 참조. 현 저장소에 검증용 커밋은 생성하지 않는다.
- 제품 코드 변경이 없어 앱 빌드·플랫폼 테스트는 미실행. CI/서버 집행은 미구현.
- 알려진 관련 커밋: 기준 커밋 외 이번 변경 커밋은 아직 없음. 최종 커밋은 이 파일의 Git 이력으로 추적한다.
- 맥락 정리 결과·메인 검토 근거: 실제 맥락 정리 담당이 context.md를 갱신하고 UPDATED와 SHA-256을 반환했다. 메인이 해당 문단·정책·작업 기록을 대조해 수락했다. 본문 필드 설명의 `추적`/`기록` 불일치를 발견하여 `기록:`으로 통일했다. 최종 문서 해시·수락은 validation.json에 기록한다.
