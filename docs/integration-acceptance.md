# v1 검증·완료 기준

기존 FEAT-001-AC-001~006, FEAT-002-AC-001~007을 Android·iOS·웹과 공통 서버에서 확인한다. 추가 V1-NAV-001(일반 초안 비복원), V1-RECOVERY-001(저장 시도 재진입 복구)을 확인한다. 빌드 성공·공통 테스트·시안 검토·실제 플랫폼 UI/서버 연동은 별도로 기록한다.

필수: 공통 공식 Unicode 벡터·한글/이모지/공백/경계 길이, DB 재시작·동시 같은 키·다른 키 동일 본문·응답 유실 재시도·최신순 동률, 저장 성공 후 조회 실패, 일반 초안 비복원/불확실 시도 복구, 실제 웹 키보드/포커스·반응형·오류/재시도. Android/iOS는 빌드와 실제 입력·키보드·뒤로·재진입 검증을 구분한다. 실행 불가능한 대상은 NOT_RUN, 모든 타깃의 필수 기준 검증 전 전체 완료 아님.
