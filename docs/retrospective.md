# 제품 기획·디자인·개발·검증 시행착오

[공통 기록 기준](../../kmp_agent/docs/task-management.md#retrospective)을 따른다. 상세 발견·재현·증거는 [피드백 원본](feedback.md)에 유지한다. 하네스 공통 원인·개선은 [하네스 회고](../../kmp_agent/docs/retrospective.md)에 연결한다.
프로그램 자동 생성은 미구현(PLANNED)이며 수행 Codex가 종료·인계 시 근거를 확인해 갱신한다.

## Codex 관리 요약

<!-- codex-retrospective:start -->

현재 확인된 제품 작업 시행착오 기록은 없다. 저장소 연결 작업을 과거 제품 작업으로 간주하지 않는다.
