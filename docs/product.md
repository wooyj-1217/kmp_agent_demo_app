# 서버 연동 메모 앱 제품 지침

## 목표·사용자·근거
- 제품 ID: MEMO-MVP. Android·iOS에서 짧은 메모를 작성해 로컬 서버에 저장하고 다시 조회한다.
- 검증 목표(CONFIRMED): 작은 제품을 완주하며 기획 → 디자인 → 개발 → 검증 → PR 흐름과 공통 하네스를 검증한다. 이번 요청은 기획 작성·검토까지만이다.
- 초기 사용자(INFERRED): 로컬 실행 환경에서 짧은 기록을 남기는 앱 사용자와 양 플랫폼에서 흐름을 검증하는 프로젝트 참여자. 시장 조사·실사용자 인터뷰는 하지 않았으며 외부 서비스 출시를 전제하지 않는다. 사용자 조사나 배포 범위 변경 시 재검토한다. 기획 진행 가능.
- SRC-001: 2026-10-13 사용자 최초 요청. SRC-002: 같은 요청의 정책 질문 세 묶음에 대한 사용자 답변(추천안 모두 선택).

## 범위
포함: 메모 목록 조회, 본문 작성·서버 저장, 저장 후 목록 반영, 로딩·빈 목록·오류·재시도, 서버 및 앱 재시작 후 저장된 데이터 조회. Android·iOS, KMP 활용, 로컬 서버.
제외: 로그인·수정·삭제·검색·오프라인 동기화·외부 서버 배포. 이번 검증 목표에 불필요하므로 제외하며 향후 확대 시 기획 담당이 새 요구사항으로 검토한다. 이번 작업에서 시안·제품 코드·서버·브랜치·PR을 생성하지 않는다.

## 기술·디자인 결정 시점
KMP 활용만 확정. 공유 범위, 플랫폼별 UI 방식, 서버 언어·프레임워크·DB, API 형식, 디자인 규칙·토큰은 UNKNOWN이다. 디자인 명세·시안·시각 검토와 API 계약·개발 준비 단계에서 담당자가 근거를 갖춰 제안한다. 현재 기획을 차단하지 않으며 특정 예제 스택을 자동 채택하지 않는다.

## 버전·운영
기획 v0.1. 최초 작성·검토 당시 제품 기준 커밋은 UNKNOWN(커밋 없음)이었다. 이번 기획 기준 버전은 이 문서를 포함하는 Git 커밋이며, 실제 해시는 Git 제외 작업 관리의 기획 인계 기록에 연결한다. 하네스 HEAD 0a212803cd240b9ab66a11e0e406767e18e34152, task-management.md·retrospective.md 미커밋 변경 존재. 사용 파일·원본 SHA-256·시작 스냅샷·diff는 Git 제외 `.harness/planning/baseline.json` 및 인접 파일에 고정했다. 실행 ID 9c017f47-8097-4b94-b983-db66d2088618. 실행 상태 원본은 `.harness/tasks/tasks.yaml`이다.
역할 간 실제 실행 인계 전 제품 Git 커밋·해당 명세 버전을 고정해야 한다. 최초 문서 검토는 미커밋 초안에서 수행했다. 커밋 전 재검토에서도 기획 검토 PASS·실제 앱 검증 NOT_RUN을 유지한다. 커밋 고정은 앱 검증 통과나 디자인 실행 완료를 뜻하지 않는다.
