# 여백 디자인 사용 규칙 D1
기획: ../requirements.md (신규 P1 작업본). 지침: 275b489fda59d4904031ae8fb445f845485603c6. 기존 제품·버전·에셋은 조사·재사용하지 않았다. 사용자 요청의 독립 신규 개발 경계를 따른다. 모든 색·컴포넌트는 이번 시안에서 생성했다.

실제 토큰 원본은 tokens.css, 상태 컴포넌트는 components.html이다. 외부 폰트/CDN/API/이미지 의존 없음. A/B HTML은 동일 tokens.css를 사용하며 레이아웃 CSS와 fixture JavaScript는 각 HTML 내부에 고정했다. 이후 비교 개정 시 기존 파일과 공유 tokens.css를 덮어쓰지 않고 새 파일명으로 보존한다.

A 카드 작업실: 탐색 204px, 그리드 유동, 편집 340~420px. B 집중형 기록장: 탐색 184px, 목록 360px, 넓은 편집 나머지. 1100px 미만은 목록과 편집 전환, 700px 미만 탐색을 목록 상단 탭으로 이동. 동일 의미의 저장/취소/삭제/오류는 두 안에서 같은 위치·표현.

forest는 주요 행동, sage/indigo/apricot는 샘플 메모의 장식 배경이며 분류나 저장 상태 의미가 없다. 메모 상태는 텍스트로 표시한다. 모서리 20px, 버튼 12px. 버튼 최소 44px. 카드 제목 최대 두 줄, 본문 4줄(A) 또는 2줄(B), 실제 내용은 편집기에서 모두 읽는다. 웹 본문 폰트 16px, 모바일 입력 16px 이상. 글자 확대 시 카드 높이는 늘어날 수 있으며 주요 버튼 숨김 금지.

검토 전용 선택기로 정상/첫 사용/로딩/저장 실패를 시연한다. 샘플 데이터는 시안 전용이며 제품 첫 실행에 주입하지 않는다. 시안은 저장소·브라우저 이력·영구 삭제 전체 정책 구현물이 아니므로 해당 AC 구현 검증에 사용하지 않는다.

선택 상태 정정: 사용자 선택권 위임 이후 순서 지적을 반영한다. A 카드 작업실 r3는 우선 검토 후보이며 독립 QA 재검토 후 메인이 selection.md에 최종 채택을 기록한다. A/B r1 보존. r2는 저장본과 draft를 분리하고 검색 지우기 및 모바일 인라인 실패 복구를 추가했다. 사용자가 직접 A를 고른 것으로 표현하지 않는다.

A-r3: QA CDP를 차단하던 브라우저 confirm 대신 HTML dialog. 취소 기본 포커스, 두 버튼 Tab 순환, Escape 취소, 호출 요소 포커스 복귀. r2 보존. 실제 접근성 동작은 독립 QA 재검토 대상.

현 검토 후보 A-r4: 버리기/필터/삭제 이탈 후 저장본을 다시 바인딩하고 활성 메모가 없으면 빈 읽기 전용·저장 비활성 편집기 표시. 모바일 목록 복귀 유지. r3 보존. 메인 실제 UI 검토와 독립 QA 증거 해석 접수 대기.

현재 검토 후보 A-r5: 첫 사용/로딩은 정상 데이터와 분리한 빈 fixture. 첫 사용 count0+선택없음 readonly+저장 disabled, 로딩 count대신 상태+검색/생성 disabled. 정상 복귀는 보관한 fixture 복구. 실제 JS 함수 논리 검사는 PASS, 브라우저 렌더링은 메인/독립 QA 접수 대기. r4 보존.
