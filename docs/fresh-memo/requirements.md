# FEAT-FRESH-MEMO 메모앱 요구사항

- 제품: 빠르게 적고 다시 찾는 개인용 메모앱. 작업명 `여백 / YEOBACK`는 가역적 제안이다.
- 대상: iOS, Android, Web. 사용자 확정 사항이다.
- 기능 ID: FEAT-FRESH-MEMO. 작업·run·공식 P 버전은 메인 실행 원장에 연결한다.
- 담당: 독립 기획 에이전트. 디자인: [design.md](design.md).
- 인계 기준: 이 파일의 미커밋 기획 작업본. 공식 인계 커밋·P 번호는 오케스트레이터가 고정한다. 마지막 승인본/CR: N/A, 신규 기획.
- 독립성: 기존 제품 기획·구현·과거 버전을 입력으로 사용하지 않고 새로 정의했다.

## 문제·사용자·목표

개인 사용자가 생각이나 할 일을 잊기 전에 기록하고, 나중에 단어 몇 개로 다시 찾는다. 첫 실행부터 가입 없이 작성할 수 있어야 하며 저장 결과를 분명하게 보여준다. 사용성 가설이며 사용자 조사로 검증된 사실은 아니다.

## MVP와 제외 범위

포함: 일반 텍스트 메모 작성·수정·조회, 기기 내 영속 저장, 제목/본문 검색, 고정, 휴지통 이동·복원·영구 삭제, 빈 상태와 저장 실패 안내, 세 플랫폼에서 같은 정책.

제외 제안: 계정·서버·기기 간 동기화, 협업, 이미지/파일 첨부, 서식 편집, 폴더/태그, 알림, 가져오기/내보내기. 초기 핵심 흐름에 집중하기 위한 가역적 범위 결정이다. 후속 필요 시 별도 기능으로 재기획하며 현재 데이터가 자동으로 다른 기기에 나타난다고 안내하지 않는다.

미결정 Q-001: 브랜드명·자동 저장·계정/동기화의 장기 필요. 현재는 작업명·명시적 저장·로컬 MVP 제안으로 진행 가능하며 외부 서비스 도입 또는 사용자 변경 요청 시 기획 재검토. 담당: 기획/오케스트레이터.

기술 미결정 Q-002: 플랫폼 최소 버전·지원 브라우저·저장 구현·실행 환경. 담당: 개발. 공통 디자인은 진행 가능하며 타깃별 완료 판정 전에 구현/검증 환경을 명시해야 한다.

다음 역할은 위 요구·정책·AC를 바탕으로 실제 화면 명세와 HTML/CSS 시안을 작성하고 시각 검토를 남긴다. 신규 최초안이므로 변경 영향/연결 CR은 N/A. 요구 변경 시 영향받는 AC·디자인·구현·검증을 함께 갱신한다. 본 문서는 구현/빌드/제품 검증 PASS의 근거가 아니다.
