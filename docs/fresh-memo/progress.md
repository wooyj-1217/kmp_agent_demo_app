# 여백 새 메모앱 — 현재 진행

이전 제품 기획·소스를 입력으로 사용하지 않은 새 실행입니다. iOS·Android·Web을 지원 대상으로 확정했고, 디자인 선택은 사용자 위임에 따라 QA를 마친 A-r5로 결정했습니다.

| 단계 | 실제 상태 |
| --- | --- |
| 기획 | 새 요구사항·정책·AC 10개 작성, 독립 의미 검토 통과 |
| 디자인 | 두 비교안 작성 후 결함 보완·실제 렌더링 QA·독립 증거 검토 통과, A-r5 채택 |
| 개발 계획 | 모듈·소유·저장 계약·검증 명령 독립 검토 통과 |
| 구현 | 새 공통 도메인, 세 플랫폼 로컬 저장, 카드 목록·편집·검색·고정·휴지통·복원 구현. 실제 검증에서 발견한 Web 접근성·입력 보완 중 |
| 검증 | 공통 JVM 8개, Android 계측 6개, iOS UI 흐름 통과 기록 보유. 이후 공유 코드 보완분의 최종 재검증 및 Web 오프라인·키보드 검사 진행 |
| 결과 정리 | 최신 소스 기준 검증·독립 QA와 산출물 정리 후 마감 예정 |

완료한 이전 검사와 최신 소스 전체 검증 완료를 구분합니다. 현재 개발/검증 단계는 아직 최종 완료가 아닙니다.

최근 확인한 iOS 흐름은 작성→고정→휴지통→복원→재시작→미저장 변경 버리기이며, 본문 원문·고정 상태·버린 변경 미포함을 실제로 확인했습니다. Web은 저장·재열기·고정 우선 정렬·휴지통·복원과 확인창 닫은 뒤 접근성 복귀를 실제 검증했습니다. 브라우저 키보드 포커스 보완의 최신 빌드와 오프라인 재실행이 남아 있습니다.

실제 native 작업·역할 실행은 `.harness/tasks/tasks.yaml`, 명령/실패/재실행과 캡처는 `.harness/fresh-memo/`에 보존합니다. 대시보드의 연결은 기존 native 원장을 참조하는 사후 표시 설정이며 원래 실행 시각·미관측 사용량을 만들어내지 않습니다.
